# My Contacts App (Basic OOPs)

This repository is intended for a basic **Contacts Application** project built using object-oriented programming concepts.

## Project Goal

Build a simple contacts manager where you can:
- Add a contact
- View all contacts
- Search contacts
- Update contact details
- Delete contacts

## OOP Concepts Practiced

- Classes and Objects
- Encapsulation
- Abstraction
- Inheritance (optional extension)
- Polymorphism (optional extension)
